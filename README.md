# 🚀 Convexa AI

> A privacy-first, on-device AI assistant that remembers conversations and helps users improve their communication skills.

---

## 🧠 Overview

Convexa is a next-generation AI assistant that goes beyond basic chat.  
It combines **conversation memory** with **real-time communication coaching** to help users grow in real-life situations like interviews, public speaking, and daily conversations.

Unlike traditional AI tools, Convexa runs entirely **on-device**, ensuring:
- 🔒 Full privacy  
- ⚡ Fast responses  
- 🌐 No internet dependency  

---

## ✨ Features

### 💬 Smart Chat
- Natural conversations using local AI  
- No cloud APIs  

---

### 🧠 Memory System
- Stores conversations locally (SQLite)  
- Recalls past interactions  
- Context-aware responses  

---

### 🎤 Practice Modes
- **Interview Mode** → Simulates real interview questions  
- **Public Speaking Mode** → Provides topics + feedback  
- **Daily Chat Mode** → Improves casual communication  

---

### 📊 Feedback System
- Analyzes responses based on:  
  - Confidence  
  - Clarity  
  - Structure  

---

### 📈 Improvement Tracking
- Compares past vs current answers  
- Helps users track growth over time  

---

## ⚙️ Tech Stack

- React Native (CLI)  
- RunAnywhere SDK (On-device AI)  
- SQLite (local storage)  
- Node.js v20  

---

## 🚀 Getting Started

### Install & Run

```bash
git clone https://github.com/your-username/convexa-ai.git
cd convexa-ai
npm install
npx react-native run-android

```
---
### ⚠️ Notes
- First launch may take a few seconds (model loading)  
- Works fully offline after setup
